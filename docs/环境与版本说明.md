# 环境与版本说明

## 1. 基本原则

所有实验必须记录环境版本。没有环境记录的实验，默认不能进入论文统计。

需要记录：

- 机器名称；
- GPU 型号与显存；
- 操作系统；
- NVIDIA driver；
- CUDA；
- Python；
- PyTorch；
- transformers；
- peft；
- datasets；
- accelerate；
- bitsandbytes；
- safetensors；
- 当前 git commit；
- 当前分支；
- 配置文件路径。

## 2. 推荐环境

两台显卡机建议尽量使用同一套 Python 依赖版本。

推荐 Python：

```text
Python 3.10 或 3.11
```

推荐核心依赖：

```text
torch
transformers
peft
datasets
accelerate
bitsandbytes
safetensors
sentencepiece
protobuf
scipy
pandas
numpy
tqdm
```

说明：

- 4070 Ti 和 3090 Ti 都使用 NVIDIA GPU，因此训练环境应使用 CUDA 版 PyTorch。
- 具体 PyTorch/CUDA 组合以机器驱动支持为准。
- 3090 Ti 可以优先尝试 bf16；如果不稳定，切换 fp16。
- 4070 Ti 当前配置使用 fp16。
- `flash-attn` 可选，不作为第一步实验必需依赖。

## 3. 环境记录文件

每台机器第一次运行第一步实验前，应生成环境记录。

建议位置：

```text
experiments/step1_vanilla_baseline/results/<machine>/env_report.txt
```

其中 `<machine>` 为：

```text
4070ti
3090ti
```

生成命令：

```bash
python experiments/step1_vanilla_baseline/scripts/check_env.py \
  > experiments/step1_vanilla_baseline/results/4070ti/env_report.txt
```

3090 Ti：

```bash
python experiments/step1_vanilla_baseline/scripts/check_env.py \
  > experiments/step1_vanilla_baseline/results/3090ti/env_report.txt
```

环境记录可以提交，因为它是轻量文本文件。

## 4. 建议安装命令

以下只是参考，具体应按机器 CUDA 版本调整。

```bash
python -m pip install -U pip
python -m pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
python -m pip install transformers peft datasets accelerate bitsandbytes safetensors sentencepiece protobuf scipy pandas numpy tqdm
```

如果 `bitsandbytes` 在 Windows 上不可用，建议在 Linux 显卡机上运行训练；本机主要负责脚本、数据分析和论文。

## 5. 实验记录要求

每次正式实验至少记录：

```text
git commit:
branch:
machine:
gpu:
config:
model:
dataset:
method:
seed:
start time:
end time:
status:
notes:
```

第一步实验的 `experiment_index.csv` 会保存一部分字段，完整环境记录放在 `env_report.txt`。

## 6. 版本变更规则

如果任一机器更新了关键依赖，需要：

1. 重新运行 `check_env.py`。
2. 更新对应 `env_report.txt`。
3. 在提交信息中说明环境变更。
4. 标注哪些实验是在新环境下运行的。
