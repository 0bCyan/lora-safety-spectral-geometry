# 统一数据集方案

## 1. 原则

4070 Ti 和 3090 Ti 使用同一个数据池、同一套划分、同一套样本 ID。

这样做的目的：

1. 降低实验管理复杂度。
2. 保证 pilot 和正式实验可比较。
3. 避免把数据差异误判为模型或方法差异。
4. 方便后续复现实验和写论文。

4070 Ti 只使用较小子集，3090 Ti 使用较大子集，但二者都从同一个数据池中按固定样本 ID 抽取。

## 2. 数据类型

第一轮只保留三类训练数据：

### 2.1 正常任务数据

用途：观察普通任务微调是否也会造成安全变化。

建议来源：

- Alpaca 小子集；
- 可选 Dolly 或 UltraChat 小子集。

第一阶段优先使用 Alpaca，减少变量。

### 2.2 风险数据

用途：制造安全压力，观察安全下降时参数变化是否更明显。

建议来源：

- PKU-SafeRLHF；
- BeaverTails。

第一阶段可以二选一。如果时间允许，再加入另一个作为补充。

### 2.3 对照数据

用途：排除“只要训练就会变”的解释。

建议构造：

- 从正常任务数据中随机抽样；
- prompt 和 response 打乱配对，形成噪声对照。

对照数据不需要引入额外外部数据集。

## 3. 统一划分

建议建立一个固定数据池：

```text
data/processed/unified_pool/
  train_normal.jsonl
  train_risk.jsonl
  train_control.jsonl
  eval_safety.jsonl
  eval_utility.jsonl
  manifest.json
```

每条样本必须有稳定 ID：

```json
{
  "sample_id": "normal_alpaca_000001",
  "split": "train",
  "family": "normal",
  "source": "alpaca",
  "prompt": "...",
  "response": "..."
}
```

后续所有训练、生成、评估都使用 `sample_id` 追踪。

## 4. 规模设置

### 4.1 4070 Ti pilot 子集

从统一数据池抽取：

- 每类训练样本：128-256；
- 每类评估样本：50-100；
- seed：1；
- 模型：Qwen3-4B；
- 目标：跑通流程，不做正式结论。

### 4.2 3090 Ti 初筛子集

从同一数据池抽取：

- 每类训练样本：512-1000；
- 每类评估样本：200-300；
- seed：3；
- 模型：Qwen3-8B；
- 目标：判断是否存在稳定规律。

### 4.3 正式实验子集

确认有信号后再扩大：

- 每类训练样本：2000-5000；
- 每类评估样本：500-1000；
- seed：3-5；
- 模型：Qwen3-8B 为主；
- 目标：支撑论文主结果。

## 5. 第一轮推荐最小设置

先做三类数据：

1. normal：Alpaca 正常任务子集；
2. risk：PKU-SafeRLHF 或 BeaverTails 风险子集；
3. control：打乱配对对照子集。

第一轮不要同时引入太多数据集。

推荐顺序：

1. 先用 Alpaca + PKU-SafeRLHF + control。
2. 如果有信号，再加入 BeaverTails 验证。
3. 如果无信号，先检查训练强度、评估集和参数分析，不急着扩数据。

## 6. 评估集

评估集与训练集分开。

建议：

- safety eval：HarmBench 小子集或 PKU/BeaverTails 留出样本；
- utility eval：Alpaca 留出样本；
- 标准能力检查：GSM8K 或 MMLU 小子集，后续加入。

第一轮评估先控制规模，重点判断方向。

## 7. 机器使用方式

### 7.1 4070 Ti

使用统一数据池中的 pilot 子集：

```text
normal: first 128-256 by sample_id
risk: first 128-256 by sample_id
control: first 128-256 by sample_id
```

只验证：

- 训练流程；
- adapter 保存；
- 参数变化分析；
- 小批量 judge。

### 7.2 3090 Ti

使用统一数据池中的初筛或正式子集：

```text
normal: first 512-1000 or 2000-5000 by sample_id
risk: first 512-1000 or 2000-5000 by sample_id
control: first 512-1000 or 2000-5000 by sample_id
```

负责：

- 正式普通 LoRA 基线；
- 后续 SpectraSafe；
- 消融实验；
- 批量生成。

## 8. 当前决定

当前决定：

- 两台显卡机使用同一个数据池。
- 第一轮优先使用 Alpaca + PKU-SafeRLHF + control。
- BeaverTails 暂作为第二安全数据源，等第一轮有信号后再加入。
- 4070 Ti 跑小子集，3090 Ti 跑大子集。
- 所有样本必须有固定 `sample_id`，方便追踪和复现。
