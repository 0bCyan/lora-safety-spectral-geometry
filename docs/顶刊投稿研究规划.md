# LoRA 安全漂移谱几何机制与 SpectraSafe 方法研究规划

## 1. 当前定位

本文不应被定位为单纯提出一个 LoRA 正则化技巧，而应定位为：

> 研究 LoRA 微调导致安全漂移的谱几何机制，并基于该机制设计训练期安全控制方法。

也就是说，SpectraSafe 不是唯一主角，而是由机制分析自然推出的方法结果。论文的核心价值应来自两部分：

1. 发现 LoRA 安全漂移中可观测、可解释、可干预的谱几何结构。
2. 基于该结构设计 SpectraSafe，并验证其相比普通参数收缩方法更能改善安全-效用权衡。

当前已有思路可以作为早期原型，但距离一区顶刊仍需要补足机制证据、干预证据、强基线和跨设置稳健性。

## 2. 顶刊导向的核心命题

建议将全文主命题收敛为：

> LoRA-induced safety drift exhibits spectral-geometric signatures, and these signatures can guide training-time control.

中文表述为：

> LoRA 微调导致的安全漂移具有谱几何特征，该特征可以用于指导训练期安全控制。

围绕这一命题，建议设置三个核心结论：

### 2.1 结论一：LoRA 安全漂移存在可测量的谱几何特征

需要证明不安全 adapter 与相对安全 adapter 在 LoRA 更新矩阵上存在稳定差异，例如：

- 全局谱量扩散；
- 少数层出现局部谱尖峰；
- 某些模块的谱变化更能解释安全退化；
- 谱范数或奇异值集中度比普通 Frobenius norm 更能解释 unsafe compliance 或 refusal retention。

### 2.2 结论二：mean 和 max 谱结构对应不同风险模式

当前 SpectraSafe 的 mean 项和 max 项不能只作为经验设计，而应与机制发现对应起来：

- mean spectral term 对应全局更新扩散；
- max spectral term 对应局部最坏层尖峰；
- 如果实验显示 mean 项主导，应明确表述为 mean-dominant mechanism；
- 如果 max 项贡献有限，可以将其定位为残余尖峰控制，而不是声称两个项同等重要。

### 2.3 结论三：SpectraSafe 比通用正则更有针对性

需要证明 SpectraSafe 不是普通 shrinkage 的换名版本。必须和以下方法对比：

- vanilla LoRA；
- weight decay；
- Frobenius regularization；
- orthogonal regularization；
- mean-only；
- max-only；
- 至少一个安全微调或训练后修补强基线，例如 SaLoRA、Safe Delta、Safe LoRA 或 SPLoRA。

## 3. 数学可行性判断

### 3.1 已成立的数学基础

LoRA 更新可写作：

```text
Delta W_l = B_l A_l
```

谱范数满足次乘性：

```text
||Delta W_l||_2 = ||B_l A_l||_2 <= ||B_l||_2 ||A_l||_2
```

因此，用 `||B_l||_2 ||A_l||_2` 作为 LoRA 更新谱范数的上界代理，在数学上是成立的。

该代理可以解释为：

- 控制线性层更新在最坏输入方向上的放大能力；
- 间接限制 LoRA 对模型内部表示空间的强扰动；
- 为安全漂移提供一个可微、可审计、可嵌入训练的结构性风险代理。

### 3.2 主要数学风险

#### 3.2.1 上界代理不一定紧

`||B_l||_2 ||A_l||_2` 只是 `||B_l A_l||_2` 的上界，不一定等于真实 LoRA 更新谱范数。

必须补充实验：

- 比较 `||B_l||_2 ||A_l||_2` 与真实 `||B_l A_l||_2` 的相关性；
- 比较二者对 unsafe compliance 和 refusal retention 的解释力；
- 如果 LoRA rank 较低，应测试直接计算 `||B_l A_l||_2` 的可行性。

#### 3.2.2 LoRA 因子存在重参数化问题

同一个 `B_l A_l` 可以由不同的 `B_l` 和 `A_l` 分解表示。因此，直接惩罚 `||B_l||_2 ||A_l||_2` 可能受到因子表示方式影响。

需要处理方式：

- 在理论部分承认这是上界代理，而非唯一函数距离；
- 在实验中比较因子代理与真实 `BA` 谱范数；
- 如有必要，增加直接 `BA` 谱正则版本作为对照；
- 避免过强表述，例如“该代理精确刻画安全风险”。

#### 3.2.3 安全漂移的一阶扰动解释只能作为动机

可以用一阶近似解释：

```text
Delta loss_safe approximately <gradient_safe, Delta W>
```

并由 Holder 不等式得到最坏方向扰动上界。但 LLM 安全行为高度非线性，因此该部分只能作为理论动机，不能作为严格安全保证。

建议表述为：

> 谱范数不是安全性的充分或必要条件，而是一个可优化的局部结构风险代理。

## 4. 机理可行性判断

### 4.1 合理假设

LoRA 在模型线性层上加入低秩更新。若某些更新方向显著放大模型内部表示，则可能改变原有拒答边界或危险请求处理路径。

因此，以下假设具有机理可行性：

> 安全漂移并非只表现为参数总量增加，而可能体现为特定层、模块或方向上的谱扩张。

### 4.2 必须补足的三类证据

#### 4.2.1 相关性证据

需要证明谱指标与安全指标存在稳定关系：

- unsafe compliance 与 layer-wise spectral norm 的相关性；
- refusal retention 与 top-k spectral spike 的相关性；
- safe non-refusal rate 与谱压缩程度的关系；
- utility score 与谱压缩程度的关系。

#### 4.2.2 定位证据

需要证明安全漂移不是全层均匀发生：

- attention 模块与 MLP 模块分开分析；
- early、middle、late layers 分开分析；
- q_proj、k_proj、v_proj、o_proj、gate_proj、up_proj、down_proj 分开分析；
- 不同 family 分开分析。

#### 4.2.3 干预证据

这是顶刊最需要的机制证据。

建议至少做：

- 对高谱层进行 post-hoc scaling，看安全是否恢复；
- 对低谱层进行同样 scaling，作为对照；
- 对随机层 scaling，作为随机对照；
- 对 top singular direction 进行缩放或移除，观察 unsafe 和 refusal 是否变化；
- 对 attention 和 MLP 分别干预，判断敏感模块。

如果只有相关性而没有干预，文章容易被认为是事后解释。

## 阶段二：机制发现实验

时间：7 月 4 日至 7 月 15 日

目标：证明 LoRA 安全漂移具有可测量的谱几何 signature。

### 必做实验

#### 5.2.1 Layer-wise spectral analysis

对每个 adapter、每个 LoRA 层计算：

- `||B_l A_l||_2`；
- `||B_l||_2 ||A_l||_2`；
- Frobenius norm；
- effective rank；
- top singular value ratio；
- layer-wise spectral variance；
- top-k spectral spike。

#### 5.2.2 Module-wise analysis

按模块统计：

- q_proj；
- k_proj；
- v_proj；
- o_proj；
- gate_proj；
- up_proj；
- down_proj。

分析 attention 和 MLP 是否呈现不同风险模式。

#### 5.2.3 Safety correlation analysis

分析谱指标与以下安全指标的关系：

- unsafe compliance；
- refusal retention；
- safe non-refusal rate；
- utility score。

建议报告：

- Pearson correlation；
- Spearman correlation；
- bootstrap confidence interval；
- family-level correlation；
- seed-level variance。

#### 5.2.4 Family-level decomposition

至少分解：

- benign_task；
- benign_drift；
- explicit_malicious；
- control_noise。

目标是判断主结论是否只由 explicit_malicious 驱动。

#### 5.2.5 Proxy validity check

比较：

- 因子谱代理 `||B_l||_2 ||A_l||_2`；
- 真实更新谱范数 `||B_l A_l||_2`。

必须回答：

> 为什么使用因子上界代理是合理的？

### 理想结果

- unsafe 越高，某些层或模块的谱尖峰越明显；
- refusal retention 越低，top-k spectral spike 越高；
- 谱范数比 Frobenius norm 更能解释安全漂移；
- 因子代理与真实 `BA` 谱范数高度相关。

### 失败处理

如果全局谱不相关，但少数层相关：

- 转向 layer-aware SpectraSafe。

如果谱范数不相关，但奇异值集中度相关：

- 将主机制改成 spectral concentration，而不是 spectral norm。

如果谱指标都不相关：

- 不建议继续以顶刊机制论文推进；
- SpectraSafe 降级为经验正则方法。

## 阶段三：干预验证实验

时间：7 月 12 日至 7 月 22 日

目标：证明谱结构不仅和安全漂移相关，而且具有一定因果解释力。

### 必做实验

#### 5.3.1 高谱层缩放

选择 top-k 高谱层，对 LoRA 更新做缩放：

```text
Delta W_l <- alpha Delta W_l
```

其中 `alpha < 1`。

观察：

- unsafe compliance 是否下降；
- refusal retention 是否上升；
- utility 是否可接受。

#### 5.3.2 低谱层缩放对照

选择 bottom-k 低谱层做同样缩放。若高谱层干预明显更有效，则支持机制假设。

#### 5.3.3 随机层缩放对照

随机选择同等数量层进行缩放，作为随机干预基线。

#### 5.3.4 模块级干预

分别干预：

- attention LoRA 更新；
- MLP LoRA 更新；
- projection-specific 更新。

判断安全漂移更集中于哪些结构。

### 加分实验

#### 5.3.5 Top singular direction intervention

对某层 LoRA 更新做奇异值分解：

```text
Delta W_l = U Sigma V^T
```

缩放或移除最大奇异值方向：

```text
Sigma_1 <- alpha Sigma_1
```

观察安全指标变化。

### 理想结果

- 高谱层缩放比低谱层缩放更能恢复安全；
- 高谱层缩放比随机缩放更有效；
- top singular direction 干预能显著影响 unsafe 或 refusal；
- utility 损失小于安全收益。

### 失败处理

如果高谱层干预恢复安全但损害效用：

- 说明安全与任务能力方向混合；
- 可引出 direction-aware 作为未来工作。

如果干预只在 malicious family 有效：

- 将机制 claim 限定为 high-risk adapter family。

如果干预完全无效：

- 降低机制表述强度；
- 不宜把“谱机制”作为顶刊主贡献。

## 阶段四：方法设计与升级

时间：7 月 18 日至 7 月 28 日

目标：基于机制结果设计 SpectraSafe 系列方法。

### 4.1 基础方法：SpectraSafe-global

当前版本：

```text
L = L_task
  + lambda_mean * mean_l sigma_l
  + lambda_max * max_l sigma_l
```

其中：

```text
sigma_l = ||B_l||_2 ||A_l||_2
```

定位：

- mean 项控制全局谱扩散；
- max 项控制局部层尖峰。

### 4.2 增强方法：SpectraSafe-layer-aware

如果阶段二发现安全漂移集中在特定层或模块，可以设计：

```text
L = L_task
  + lambda_mean * sum_l w_l sigma_l
  + lambda_max * max_l w_l sigma_l
```

其中 `w_l` 根据机制分析确定。

可选权重来源：

- safety correlation；
- high-risk module；
- middle-layer sensitivity；
- intervention sensitivity。

### 4.3 可选方法：SpectraSafe-direction-aware

如果 top singular direction 干预结果很强，可以进一步设计方向约束。

但该版本不建议作为 8 月投稿的必做项，因为实现、解释和稳定性风险较高。

### 必做消融

- vanilla；
- mean-only；
- max-only；
- mean + max；
- layer-aware；
- Frobenius regularization；
- orthogonal regularization；
- weight decay。

### 强基线

至少选择一到两个可复现方法：

- SaLoRA；
- Safe Delta；
- Safe LoRA；
- SPLoRA。

### 理想结果

- SpectraSafe-global 优于普通正则；
- layer-aware 进一步提升安全-效用权衡；
- mean-only 贡献主要平均收益；
- max 或 layer-aware 对尖峰风险有补充作用。

### 失败处理

如果 layer-aware 没有提升：

- 保留 global 作为主方法；
- 将 layer-aware 作为负结果或局限。

如果 max 项无贡献：

- 不强行声称双项同等重要；
- 改为 mean-dominant spectral control。

如果 Frobenius 也表现很好：

- 方法新颖性下降；
- 需要把论文重点转向机制解释，而不是性能优势。

- 顶刊主线风险极高。

应对：

- 检查是否应使用奇异值集中度、effective rank 或层间方差；
- 改为研究其他几何指标；
- 将 SpectraSafe 降级为经验正则。

### 8.2 只有部分 family 有效

影响：

- 泛化性不足。

应对：

- 将结论限定为高风险 adapter family；
- 强化 family-level 解释；
- 避免声称普遍适用。

### 8.3 干预实验无效

影响：

- 机制证据不足。

应对：

- 将机制表述从因果降级为相关；
- 加强训练期方法实验；
- 作为局限报告。

### 8.4 SpectraSafe 不优于普通正则

影响：

- 方法新颖性不足。

应对：

- 强化机制分析；
- 尝试 layer-aware 或 direction-aware；
- 改写为“谱机制解释 + 正则化验证”，而不是“方法 SOTA”。

### 8.5 效用损失过大

影响：

- 安全收益可能只是模型变弱。

应对：

- 降低 lambda；
- 画 safety-utility tradeoff curve；
- 报告 safe non-refusal，证明不是全面拒答。

## 10. 当前最优研究策略

不要把所有支线都押成必成项。主线只保留三件事：

1. 发现谱几何 signature；
2. 用干预证明它不只是事后相关；
3. 基于它设计 SpectraSafe，并证明优于普通正则。

其他内容均作为增强项：

- layer-aware；
- direction-aware；
- adapter composition；
- human validation；
- multi-judge；
- cross-backbone。

如果增强项失败，不应破坏主线。失败结果可以转化为局限、边界分析或未来工作。
