# Release Gates

A paper release is blocked unless every applicable gate passes.

## Scientific identification

- [ ] equal cumulative dose verified exactly;
- [ ] temporal schedules differ only in registered placement;
- [ ] three seeds complete for every principal arm;
- [ ] final-checkpoint sequence-supervision result replicated;
- [ ] late contribution measured at frozen checkpoints;
- [ ] second setting completed or scope explicitly lowered;
- [ ] prompt-disjoint confirmation executed once.

## Measurement

- [ ] final component rubric frozen before target labels;
- [ ] A/B calibration and duplicates pass;
- [ ] adjudication follows the frozen rule;
- [ ] human-validity subset completed;
- [ ] conditional and unconditional quality both reported;
- [ ] utility remains a separate endpoint;
- [ ] old free-form semantic family is not a primary result.

## Statistics

- [ ] seed-level effects reported;
- [ ] prompt pairing preserved;
- [ ] hierarchical or seed-stratified uncertainty reported;
- [ ] smallest effects of interest reported with thresholds;
- [ ] multiplicity policy stated;
- [ ] missing runs remain visible;
- [ ] no seed-prompt pseudo-replication.

## Reproducibility

- [ ] source manifest hashes pass;
- [ ] formal command manifest frozen;
- [ ] environment reports present;
- [ ] output directories unique;
- [ ] anchor exposure manifests present;
- [ ] result-file hashes present;
- [ ] analysis and figure code deterministic;
- [ ] LaTeX compiles cleanly.

## Claim audit

- [ ] title does not imply a validated method;
- [ ] abstract states model/data scope;
- [ ] causal wording is limited to identified interventions;
- [ ] temporal-placement claim is conditioned on P1;
- [ ] gradient contribution is not called a proven mediator;
- [ ] no cross-model claim before P5;
- [ ] CDR-OPC/CSPR are not reported as validated Paper A methods;
- [ ] all negative results are bounded, not universal.

## Artifact hygiene

- [ ] no API keys, tokens, private paths, or personal data;
- [ ] no large checkpoints or raw reviewer caches committed;
- [ ] generated artifacts trace to normalized data;
- [ ] release manifest and commit SHA recorded.
