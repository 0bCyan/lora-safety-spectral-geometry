# LoRA 安全漂移谱几何研究

本仓库用于管理 LoRA 安全漂移谱几何机制与 SpectraSafe 方法研究。

当前协作方式：

- 本机：研究规划、脚本开发、数据分析、论文写作。
- 显卡机 1：实验训练与小规模验证。
- 显卡机 2：正式训练、批量生成与干预实验。
- 强 judge：API 评估，结果缓存后进入 `results/`。

## 目录结构

```text
configs/          实验配置
data/             小型样例数据与数据说明
docs/             研究规划、实验安排、会议记录
paper/            中文论文初稿与图表素材
scripts/          命令行脚本
src/              可复用代码
results/          轻量统计结果与最终表格
```

大模型权重、adapter、缓存、生成回答和 API judge 缓存默认不提交到 git。
