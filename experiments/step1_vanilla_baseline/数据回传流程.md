# 第一步实验数据回传流程

## 1. 总原则

显卡机负责训练、生成和提取轻量指标；本机负责汇总、统计、画图和写作。

默认不把 adapter 权重回传到 git，也不把大规模生成回答提交到 git。返回给本机的主要是轻量结果文件。

## 2. 产物分级

### 2.1 必须返回

这些文件必须返回给本机，并可以提交到实验分支：

```text
experiments/step1_vanilla_baseline/results/<machine>/env_report.txt
experiments/step1_vanilla_baseline/results/<machine>/experiment_index.csv
experiments/step1_vanilla_baseline/results/<machine>/spectral_metrics/*.jsonl
```

用途：

- 记录环境；
- 追踪实验状态；
- 分析 adapter 参数变化。

### 2.2 建议返回

这些文件建议返回给本机，但是否提交取决于大小和敏感性：

```text
experiments/step1_vanilla_baseline/results/<machine>/generations/*.jsonl
```

如果文件较小，可以返回并用于后续 API judge。

如果文件较大，应先压缩或只返回抽样版本。

### 2.3 默认不返回

这些文件默认不返回本机，也不提交 git：

```text
experiments/step1_vanilla_baseline/results/<machine>/adapters/
experiments/step1_vanilla_baseline/results/<machine>/logs/
```

原因：

- adapter 权重可能较大；
- checkpoint 和日志会快速膨胀；
- 本机主要做统计分析，不需要反复加载完整 adapter。

### 2.4 例外情况

如果后续需要本机复查某个 adapter，可以只回传单个 adapter，并放在 git 忽略目录中，不提交。

推荐路径：

```text
experiments/step1_vanilla_baseline/results/local_review/adapters/
```

## 3. 4070 Ti 回传流程

4070 Ti 第一轮只跑 pilot。

每个 family 训练完成后，立即在 4070 Ti 上运行参数提取：

```bash
python experiments/step1_vanilla_baseline/scripts/analyze_adapter.py \
  --config experiments/step1_vanilla_baseline/configs/4070ti_qwen3_4b.json \
  --family normal \
  --seed 1
```

然后返回：

```text
results/4070ti/env_report.txt
results/4070ti/experiment_index.csv
results/4070ti/spectral_metrics/*.jsonl
```

如果已经生成回答，也返回：

```text
results/4070ti/generations/*.jsonl
```

4070 Ti 不需要回传 adapter，除非训练或分析异常，需要本机复查。

## 4. 3090 Ti 回传流程

3090 Ti 负责正式初筛。

每个 seed / family 训练完成后，先在 3090 Ti 本地完成：

1. adapter 保存；
2. 参数变化提取；
3. 安全评估回答生成；
4. 正常任务评估回答生成。

然后返回：

```text
results/3090ti/env_report.txt
results/3090ti/experiment_index.csv
results/3090ti/spectral_metrics/*.jsonl
results/3090ti/generations/*.jsonl
```

adapter 仍然默认留在 3090 Ti 本地。

## 5. 回传方式

推荐方式：

1. 显卡机在实验分支下运行。
2. 只把轻量结果复制到仓库对应路径。
3. 对轻量结果执行 git add / commit / push。
4. 本机 git pull 后分析。

如果生成回答文件较大，不直接提交，可使用压缩包或网盘传给本机。

## 6. 建议提交名称

4070 Ti 返回结果：

```text
结果：回传4070第一步指标
```

3090 Ti 返回结果：

```text
结果：回传3090第一步指标
```

如果包含生成回答：

```text
结果：回传第一步生成回答
```

## 7. 本机分析入口

本机收到 `spectral_metrics/*.jsonl` 后，进行：

- 汇总每个 adapter 的平均变化；
- 比较 normal / risk / control；
- 按层分析；
- 按模块分析；
- 判断是否有稳定差异。

后续会在本实验目录增加汇总脚本：

```text
experiments/step1_vanilla_baseline/scripts/summarize_spectral_metrics.py
```

运行方式：

```bash
python experiments/step1_vanilla_baseline/scripts/summarize_spectral_metrics.py
```

输出位置：

```text
experiments/step1_vanilla_baseline/results/summary/
```
