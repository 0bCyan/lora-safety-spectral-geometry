## 3. 需要补充的测评任务

base safety 生成后，运行本地 safety 测评：

```bash
python experiments/step1_vanilla_baseline/scripts/local_safety_judge.py
```

该脚本会自动读取 `results/4070ti/generations/*_safety.jsonl`。

utility 生成结果暂不做自动打分，先回传给本机检查：

- 是否有空回答；
- 是否回答明显跑偏；
- 回答长度是否异常；
- 三类 adapter 是否明显牺牲正常任务能力。
