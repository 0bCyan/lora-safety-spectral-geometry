# 第一步机制分析数据字典

## 1. 数据来源

输入数据来自：

```text
experiments/step1_vanilla_baseline/results/4070ti/spectral_metrics/
experiments/step1_vanilla_baseline/results/4070ti/local_judge/
```

分析产物来自：

```text
experiments/step1_vanilla_baseline/analysis/
```

## 2. 表格归类

### 2.1 `tables/spectral_long.csv`

逐层逐模块长表。

每一行表示：

> 一个 adapter seed 中，一个 LoRA 层的一个模块。

用途：

- 细粒度分析；
- 重新聚合；
- 后续画图；
- 检查局部尖峰。

### 2.2 `tables/layer_summary.csv`

按 `family + layer_index` 聚合。

用途：

- 比较不同数据场景在不同层的谱变化；
- 生成逐层热图；
- 找中间层、浅层或深层差异。

### 2.3 `tables/module_summary.csv`

按 `family + module + block_type` 聚合。

用途：

- 比较 attention 与 MLP；
- 比较 q/k/v/o_proj 与 gate/up/down_proj；
- 判断风险是否集中在某类模块。

### 2.4 `tables/family_summary.csv`

按 `family` 聚合。

用途：

- 快速比较 normal、risk、control 的总体谱量；
- 只作为粗粒度参考。

### 2.5 `tables/seed_summary.csv`

按 `family + seed` 聚合。

用途：

- 观察 seed 间波动；
- 判断结果是否稳定。

## 3. 图表归类

### 3.1 `figures/layer_heatmap.svg`

逐层谱范数热图。

横轴：

- 模型层编号。

纵轴：

- 数据场景：normal、risk、control。

颜色：

- 平均真实更新谱范数。

### 3.2 `figures/module_bar.svg`

模块级谱范数柱状图。

用途：

- 比较 q/k/v/o_proj 和 gate/up/down_proj。

### 3.3 `figures/safety_spectral_scatter.svg`

安全表现与全局谱量散点图。

横轴：

- 平均真实更新谱范数。

纵轴：

- 危险遵从率。

用途：

- 展示全局谱均值不能单独解释所有安全差异。

## 4. 字段说明

### 4.1 实验字段

| 字段 | 含义 |
|---|---|
| experiment_id | 实验编号 |
| family | 数据场景 |
| seed | 随机种子 |
| layer_index | 模型层编号 |
| module | LoRA 注入模块 |
| block_type | attention、mlp 或 other |

### 4.2 谱指标字段

| 字段 | 含义 |
|---|---|
| spectral_proxy | 因子谱代理 `||B||_2 ||A||_2` |
| delta_spectral_norm | 真实 LoRA 更新 `BA` 的谱范数 |
| delta_fro_norm | LoRA 更新的 Frobenius 范数 |
| top_singular_ratio | 最大奇异值占奇异值总和比例 |
| effective_rank | 基于奇异值分布的有效秩 |
| rank | LoRA rank |

## 5. 数据场景说明

| family | 场景 | 解释 |
|---|---|---|
| normal | 正常任务微调 | Alpaca 正常任务子集 |
| risk | 风险内容微调 | PKU-SafeRLHF-QA 风险样本 |
| control | 噪声/错配微调 | Alpaca prompt 和 response 打乱配对 |

## 6. 当前解释边界

当前分析只能说明：

1. 不同数据场景会导致可观测的 LoRA 谱结构差异。
2. risk 的安全退化稳定，但全局谱均值不是最高。
3. control 的谱量较高，但行为不稳定。
4. 机制分析应进一步关注层级、模块和局部尖峰。

当前分析不能说明：

1. 谱结构已经具有因果作用。
2. 全局谱均值可以直接预测安全漂移。
3. 4070 Ti 的 Qwen3-4B pilot 可以替代正式 3090/Qwen3-8B 实验。
