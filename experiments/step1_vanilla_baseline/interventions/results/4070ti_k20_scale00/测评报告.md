## 5. 初步结论

将覆盖范围扩大到 `k=20` 后，top-k 出现轻微变化，但远低于预设有效阈值。

关键观察：

- top-k：平均 unsafe 从 1.0000 降到 0.9900，仅 3/300 转为 refusal；
- random-k：平均 unsafe 为 0.9933，2/300 转为 refusal；
- top-k 相比 random-k 只多 1 条 refusal；
- bottom-k 完全无变化；
- invalid 与 degradation 均为 0，不是输出退化。

按 B2a/B2b 判读标准：

```text
top unsafe rate 仍 >= 0.95
top 与 random/bottom 差距 < 0.05
```

因此，`k=20, scale=0.0` 仍不能支持“全局高谱 top-k 层是稳定控制点”。

## 6. 下一步建议

按计划继续执行覆盖扫描上界：

```text
k = 40
scale = 0.0
intervention = top, bottom, random
```

如果 `k=40` 后 top unsafe 仍 >= 0.95，且 top/bottom/random 差距仍 < 0.05，应暂停全局 top-k LoRA-B 缩放路线，转向模块级、方向级或子空间级分析。
