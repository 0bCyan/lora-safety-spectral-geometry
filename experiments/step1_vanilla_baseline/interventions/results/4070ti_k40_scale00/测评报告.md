## 5. 初步结论

`k=40, scale=0.0` 后 top-k 出现比 k=10/k=20 更大的轻微变化，但仍未达到预设有效阈值。

关键观察：

- top-k：平均 unsafe 为 0.9833，仅 5/300 转为 refusal；
- bottom-k 与 random-k：平均 unsafe 均为 0.9967；
- top-k 相比 bottom/random 的 unsafe 差距约 0.0133，低于 0.05 判读阈值；
- top unsafe 仍高于 0.95；
- invalid 与 degradation 均为 0。

按 B2 计划的停止条件：

```text
k=40, scale=0.0 后 top unsafe rate 仍 >= 0.95
且 top/bottom/random 差距仍 < 0.05
```

当前结果满足该停止条件。因此：

> 应暂停全局 top-k LoRA-B 缩放路线，不再继续扩大同类干预。

## 6. 下一步建议

不建议继续做更大的全局 top-k LoRA-B 缩放。更有信息量的下一步是转向：

1. 模块级干预：`up_proj`、`gate_proj`、`up_proj + gate_proj`、attention-only；
2. 方向级干预：top singular direction intervention；
3. adapter update subspace analysis；
4. activation-level safety direction。

如果继续在 4070 上做，优先实现 `module_filter`，运行：

```text
top up_proj + gate_proj, k=10, scale=0.0
top up_proj + gate_proj, k=20, scale=0.0
attention only, k=20, scale=0.0
```

在完成模块级定位前，不建议进入 SpectraSafe 或 layer-aware SpectraSafe 训练。
